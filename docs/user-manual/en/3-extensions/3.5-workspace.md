# 3.5 Workspace Files & Daily Memory

> ⚠️ **This feature has been removed in this fork.**

The Workspace panel originally served OpenClaw only, managing the workspace configuration files and the daily memory journal under `~/.openclaw/workspace/`.

This fork keeps only three apps — Claude Code, Codex, and Pi — so the **frontend Workspace component and its backend commands have been removed**. The Workspace entry no longer appears in the navigation bar, and CC Switch no longer manages any workspace files or daily memory content.

This page is kept only to document where the feature went; if you still need those files, edit them manually in the corresponding directory.
