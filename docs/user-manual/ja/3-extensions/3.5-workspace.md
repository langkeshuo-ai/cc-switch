# 3.5 ワークスペースファイルとデイリーメモリー

> ⚠️ **この機能は本フォークで削除されました。**

ワークスペースパネルは元々 OpenClaw 専用で、`~/.openclaw/workspace/` 配下のワークスペース設定ファイルとデイリーメモリージャーナルを管理していました。

本フォークは Claude Code、Codex、Pi の 3 つのアプリのみを保持するため、**フロントエンドのワークスペースコンポーネントとバックエンドコマンドは削除されました**。ナビゲーションバーにワークスペースの入口は表示されなくなり、CC Switch がワークスペースファイルやデイリーメモリーの内容を管理することもありません。

このページは機能の移行先を説明するために残しています。引き続きこれらのファイルを扱いたい場合は、対応するディレクトリを直接手動で編集してください。
